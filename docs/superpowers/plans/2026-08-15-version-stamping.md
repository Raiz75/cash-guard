# Build-time SemVer Stamping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `package.json`'s `"version"` the single source of truth and stamp it into `public/sw.js`, `public/manifest.webmanifest`, and a generated `lib/version.ts` at build time, surfacing it as a "Version X" line in Settings.

**Architecture:** A `scripts/stamp-version.mjs` Node ESM script runs before `next build`. It reads SemVer from `package.json`, rewrites the `const VERSION = …;` line in `sw.js` (the byte change that drives the PWA update detector), adds/updates `"version"` in the manifest, and regenerates `lib/version.ts`. The script fails loudly on a missing/invalid version and is idempotent across same-version builds.

**Tech Stack:** Node ≥ 20.9 (machine has v24.14.0), plain Node `node:fs`/`node:path` — no new dependencies, no test runner (verification is build + lint + manual grep checks).

## Global Constraints

- Node ≥ 20.9 required; this machine has Node v24.14.0. Verification is `npm run build` and `npm run lint` from the repo root; both must pass.
- The version is SemVer, read from `package.json` `"version"`. The stamp fails loudly (non-zero exit) if it is missing or not SemVer.
- `sw.js`'s `const CACHE = "cash-guard-v" + VERSION;` line is unchanged — only the `VERSION` literal is rewritten.
- `lib/version.ts` is a GENERATED file — it carries a "generated, do not edit" notice, NOT the full agent-notes header. `public/sw.js` and `public/manifest.webmanifest` keep their existing formats; `sw.js`'s agent-notes header must be kept current.
- `next dev` must NOT stamp; only the production `build` script runs the stamp.
- No new runtime dependencies, no API routes, no server.
- Settings uses semantic tokens only (`text-muted-foreground` for the version line).

### Task 1: Stamp script + build wiring + first stamp

**Files:**
- Create: `scripts/stamp-version.mjs`
- Modify: `package.json` (build script)
- Modify: `public/sw.js` (header only — the VERSION line gets stamped by the build)
- Modify: `public/manifest.webmanifest` (stamped by the build)
- Create: `lib/version.ts` (generated by the build)

**Interfaces:**
- Produces: `lib/version.ts` exporting `export const APP_VERSION: string` (a string literal of the current SemVer, e.g. `"0.1.0"`). Later task (Task 2) imports it.

- [ ] **Step 1: Create the stamp script**

Create `scripts/stamp-version.mjs` with this exact content:

```js
import { readFileSync, writeFileSync } from "node:fs";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const root = join(dirname(fileURLToPath(import.meta.url)), "..");
const semverPattern = /^\d+\.\d+\.\d+(?:-[0-9A-Za-z.-]+)?(?:\+[0-9A-Za-z.-]+)?$/;

const pkg = JSON.parse(readFileSync(join(root, "package.json"), "utf8"));
const version = pkg.version;

if (typeof version !== "string" || !semverPattern.test(version)) {
  console.error(`[stamp-version] missing or invalid "version" in package.json: ${version}`);
  process.exit(1);
}

const swPath = join(root, "public", "sw.js");
let sw = readFileSync(swPath, "utf8");
if (!/const VERSION = /.test(sw)) {
  console.error('[stamp-version] could not find "const VERSION = " in public/sw.js');
  process.exit(1);
}
sw = sw.replace(/const VERSION = [^;]+;/, `const VERSION = "${version}";`);
writeFileSync(swPath, sw);

const manifestPath = join(root, "public", "manifest.webmanifest");
const manifest = JSON.parse(readFileSync(manifestPath, "utf8"));
manifest.version = version;
writeFileSync(manifestPath, `${JSON.stringify(manifest, null, 2)}\n`);

const versionPath = join(root, "lib", "version.ts");
const ts = `// GENERATED FILE - do not edit. Regenerate with \`npm run build\`.\nexport const APP_VERSION = "${version}";\n`;
writeFileSync(versionPath, ts);

console.log(`[stamp-version] stamped v${version}`);
```
